# gift-exchange

Randomly assign secret santa gift exchange assignments!

## Usage

1. Create a CSV file named `gift_exchange_2025.csv` with column headers "Name" and "Bought For" and list of family member names and their previous gift recipients.
2. Install the required dependencies using `pip install -r requirements.txt`.
3. Run the script using `python -m gift_exchange`.
4. The script will output the secret santa assignments to the console.
